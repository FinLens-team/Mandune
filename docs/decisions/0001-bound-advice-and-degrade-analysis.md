# ADR-0001: Bound Advice and Degrade Analysis Explicitly

- Status: Accepted
- Date: 2026-07-24

## Context

年轻轻投资者需要可行动的复盘。只复述资讯无法回答“下一步关注什么”，直接给出精确交易指令又会掩盖个人约束、数据缺口和市场不确定性。

实际分析还会遇到四项用户约束缺失、持仓信息不完整、市场数据过期或证据冲突。把所有不完整输入都视为失败，会让产品在常见情况下失去价值；在缺口存在时输出完整结论，则会制造虚假确定性。

## Decision

FinLens 只给方向性建议，包括暂停继续增加某项持仓、降低某类暴露、调整配置或关注方向，以及改变风险范围的定性表达。产品不提供精确金额、份额、仓位比例、价格点位或交易时点，也不替用户执行交易。

数据或用户约束不足时，分析按充分程度降级为“有限分析”或“仅观察”。结果必须列出可确认内容、缺失信息、缺口影响和重新评估所需信息。只有仍有证据支持时，有限分析才可以保留最保守的方向性建议。

## Consequences

- 输出必须能把每项建议追溯到证据和分析结论。
- 产品需要把未知项作为一等内容展示，而不是隐藏在通用免责声明中。
- 某些问题只能得到观察项和补数建议，产品接受这一限制。
- 产品不能以免责声明为理由生成精确交易指令。
- 评审可以用缺失、过期和冲突数据验证降级行为。

## Rejected Alternatives

### Only Summarize Information

该方案风险较低，但不能完成用户从复盘到下一步方向的核心任务。

### Refuse Whenever Data Is Incomplete

该方案忽略个人持仓数据经常不完整的现实，也丢弃了缺口之外仍可确认的信息。

### Give Exact Trades with a Disclaimer

免责声明不能修复精确指令带来的责任越界和虚假精确性，因此不采用。
