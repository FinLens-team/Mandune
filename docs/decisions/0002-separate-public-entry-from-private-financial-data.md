# ADR-0002: Separate Public Entry from Personal Financial Data

- Status: Accepted
- Date: 2026-07-24

## Context

FinLens 需要通过公开响应式 Web、NFC 和二维码降低现场体验门槛。与此同时，持仓、用户约束、投资问题和个性化分析属于个人金融数据。二维码和 NFC 链接容易被拍摄、转发或在共享设备上打开，因此“持链访问”不能被当作隐私控制。

## Decision

公开访问只适用于产品入口、空白体验和明确标注的示例内容。用户提供的持仓、约束、问题和个性化分析沿用独立的私密边界，不因入口公开而自动公开。

NFC、二维码和普通分享链接不得编码个人金融数据。任何面向公开展示的示例必须使用虚构数据或经过明确确认的非个人数据，并与用户数据清楚区分。

## Consequences

- 现场观众可以直接打开产品，但不会因获得入口链接而看到他人的持仓或分析。
- 产品流程必须清楚区分示例数据、用户输入和外部市场信息。
- 演示材料和可分享页面需要单独检查个人金融数据泄漏风险。
- 访问便利性不能作为扩大数据收集或公开范围的理由。
- 具体的数据保存与访问机制可以演进，但必须保持这一产品边界。

## Rejected Alternatives

### Treat an Unlisted Link as Private

链接可以被转发、记录或误发，不能提供可靠的个人金融数据保护。

### Put Portfolio Data in NFC or QR Parameters

该方案减少输入步骤，但会让敏感信息暴露在标签、图片、浏览记录和转发链路中。

### Remove Public Access Entirely

该方案保护边界，但不必要地牺牲比赛现场和移动端的低门槛体验。
