# 满懂分析契约

## 1. 职责

分析契约把一个用户明确生成的组合快照，转换为一份可验证、可降级的每日复盘。它约束输入、证据、结论和模型边界，不规定模型供应商、框架、传输协议或存储实现。

## 2. 输入契约

一次分析请求冻结以下输入：

- `snapshot_id` 与创建时间；
- 用户逐行确认的完整结构化持仓清单，覆盖基金、ETF 和 A 股；
- 每行的资产身份、持仓规模依据、观察日期和明确的未知字段；
- 投资期限、近期流动性需求、可承受回撤和投资目标，包含未填写或 `unknown` 状态；
- 主题标识；
- 分析开始时间、证据截止时点和所采用的最新完整交易日。

“完整结构化持仓”指模型收到快照内的全部已确认行，而非只收到摘要或抽样。它不表示每个字段都有已知值；未知值必须以类型化状态保留。

原始截图、个人身份、联系方式、账户名称、账户号码、工作区访问凭据和无关截图文字不得进入分析输入。截图只负责产生待复核草稿，删除规则见 [`demo-v1.md`](./demo-v1.md)。

## 3. 证据契约

结构化证券数据由 PandaAI 集成获取，相关事件由 Bocha 搜索发现。Bocha 搜索结果只是发现线索；物质性事件必须回到可定位的原始或权威来源核验后，才可以支持结论。供应商事实与验收门槛见 [`../integrations/pandaai-bocha.md`](../integrations/pandaai-bocha.md)。

每项证据至少记录：

- 稳定的证据标识；
- 对应资产或组合范围；
- 指标或事件类型；
- 值、单位及规范化说明（如适用）；
- 原始或权威来源名称与定位信息；
- 市场观察时间或事件发布时间；
- 获取时间；
- `available`、`stale`、`ambiguous`、`unsupported`、`conflicting`、`rate_limited`、`failed` 或 `unverified` 状态；
- 会影响解释的限制、修订或冲突。

结构化行情与净值以最新完整交易日为基准。获取时间不能冒充市场观察时间，搜索摘要不能冒充原始来源，缺失值不能由模型补写。

## 4. 分析流水线

分析按以下可观察阶段推进：

1. 校验并冻结快照；
2. 解析资产身份与覆盖范围；
3. 获取 PandaAI 结构化数据；
4. 通过 Bocha 发现持仓相关事件并核验主要来源；
5. 计算可复算的组合暴露和约束冲突；
6. 形成结论、方向性建议、未知项和限制；
7. 生成主题叙事并校验输出契约；
8. 保存结果或返回有限/不可用状态。

Agent 观测台可以显示阶段、覆盖数量、等待、重试和失败，但不得展示模型思维链。阶段状态必须来自真实任务状态，不能只按计时器播放。

## 5. 结果契约

结果状态只能是：

- `supported`：现有输入和证据支持观象长笺表达的全部物质性结论；
- `limited`：部分缺口使结论范围缩小，但仍有证据支持有限的方向性建议；
- `observation_only`：只能呈现事实、观察项和补数建议；
- `unavailable`：没有足够证据形成可展示的观象长笺。

前三种状态可以形成同一张观象长笺的数据；`unavailable` 显示原因和恢复路径，不伪装成正常结果。观象长笺数据至少包含：

- 组合快照、分析时间、最新完整交易日和证据截止时点；
- 持仓覆盖与未覆盖清单；
- 四项约束及未知状态；
- 结论列表；
- 方向性建议及触发依据；
- 证据引用；
- 未知、冲突、假设与限制；
- 与当前持仓直接相关的必要概念解释；
- 风险提示；
- 主题正面和理性证据背面所需的表现数据。

每项物质性结论必须引用至少一项确认输入、派生结果或已核验证据。内容需区分：

- `observed`：确认输入或带时点证据；
- `derived`：可从输入、证据和公开规则复算的结果；
- `generated`：模型生成的解释和叙事。

`generated` 不能成为 `observed` 的来源，也不能新增证据区不存在的事实、因果或确定性。

## 6. 模型输入与输出边界

模型可以接收：

- 快照中的完整结构化持仓；
- 四项约束及未知状态；
- 已规范化的证据和来源元数据；
- 可复算的派生结果；
- 允许的建议边界、输出结构和主题表现指令。

模型不得接收原始截图、身份信息、联系方式、账户名称或号码、工作区访问凭据、供应商密钥或与复盘无关的截图文本。完整持仓载荷不得进入默认日志、分析事件、公开资源或测试快照。

模型输出必须通过带版本的结构校验和内容边界检查。超时、畸形输出、缺少证据引用、越界交易指令或主题正面与理性证据背面结论不一致时，该次输出无效；有限重试后返回 `limited`、`observation_only` 或 `unavailable`，不得展示未经校验的部分文本。

## 7. 建议边界

允许的建议只表达定性方向，例如维持观察、暂停继续增加、降低集中暴露、提高可用资金关注度或等待数据确认。每项建议都要指出触发它的持仓、约束、派生结果或证据。

禁止输出精确金额、份额、仓位比例、价格点位、买卖日期或时刻，也禁止代客操作、收益保证、胜率承诺和持牌意见暗示。风险提示不能为越界建议免责。

主题只重写表现。对相同快照和证据，主题不得改变证据选择、派生结果、覆盖状态、风险判断或方向性建议。“东方观象”不得把相关性写成因果，也不得用吉祥物语气催促交易。

## 8. 缺口与超时

缺失、过期、含糊、不支持、冲突或无法核验的数据保持为未知，并明确指出受影响的持仓和结论。四项约束缺失时仍可分析，但依赖该约束的个性化判断必须缩小或取消。

实时路径以 90 秒完成为目标，以 180 秒为硬截止。到达硬截止时停止未完成的供应商和模型任务；只有现有已核验证据足够时才生成有限结果，否则返回 `unavailable`。硬截止后迟到的响应不得静默改写已完成结果。

示例路径可以复用缓存的 PandaAI 结构化证据和已核验事件证据，但必须保留原始观察时间、获取时间、缓存状态和来源。缓存示例不得计入实时路径的 90 秒目标证明，也不得证明供应商实时可用。

## 9. 验收矩阵

| 场景 | 必须观察到的结果 |
|---|---|
| 全部持仓和证据可用 | 每项物质性结论均有输入或证据引用，建议保持方向性 |
| 一项约束未知 | 允许继续，依赖该约束的结论明确受限 |
| 部分资产不支持 | 资产仍在覆盖清单，组合结论不假装完整 |
| 行情过期或获取失败 | 不制造当前值；受影响结论进入有限或仅观察 |
| Bocha 只有聚合摘要 | 摘要不作为物质性结论证据，事件保持未核验 |
| 来源相互冲突 | 保存冲突关系并缩小结论，不静默选择有利值 |
| 模型收到输入 | 请求含完整结构化持仓，但不含原图、身份或账户详情 |
| 模型输出越界或畸形 | 不显示部分结果；有限重试后降级 |
| 主题切换对照 | 理性结论、证据、覆盖、风险和建议完全一致 |
| 180 秒硬截止 | 未完成任务停止，只有有限或不可用结果 |
| 历史重放 | 同一版本输入和证据得到同一理性结果，不采纳后来数据 |

主动查询不属于本契约。任何后续问答能力都不能通过复用本分析接口绕过证据、隐私或建议边界。
