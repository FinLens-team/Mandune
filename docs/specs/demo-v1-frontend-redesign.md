# 满懂 Demo V1 前端重塑规格

- 状态：`Accepted for implementation`
- Issue：#67 / MD-022
- 产品行为基线：[`demo-v1.md`](./demo-v1.md)
- 分析边界：[`analysis-contract.md`](./analysis-contract.md)
- 视觉实现基线：[`../design/demo-v1-visual-system.md`](../design/demo-v1-visual-system.md)

## 1. 问题

现有 S0-S10 已能完成随机体验闭环，但部分界面仍停留在功能拼装或占位状态：S1 没有形成明确的主题卡牌仪式，S4/S8 没有统一使用兜兜素材，抽屉和确认层缺少完整退场，S9 不是真正连续的双面长笺，多个关键屏缺少 768px、200% 文本和视觉截图验收。

本次重塑必须把用户已经确认的逐屏形态完整保存并实现。后续会话压缩、Builder 分工或代码重构不得把本规格缩写成模糊的“优化 UI”，也不得由模型自行新增页面、主题、字段、文案、动画或产品行为。

## 2. 目标与场景

目标用户是在通勤、午休或晚间使用手机或桌面浏览器进行每日持仓复盘的年轻轻投资者。界面先帮助用户确认数据身份、证据时点、分析覆盖和未知边界，再通过现代东方观象的叙事与兜兜降低阅读负担。

交付结果是一次完整、统一的 S0-S10 重塑，而不是只打磨比赛高光屏。新用户完成首次引导、随机体验身份确认、主动复盘和长笺核证；回访用户快速进入同一匿名私密工作区，并能继续查看持仓、历史和关于。

## 3. 已确认的设计决策

1. 现有产品、分析、隐私和 Accepted 视觉契约优先于新视觉偏好。冲突时进行契约归一，不逐值照搬慢动画、大圆角、弹跳或装饰光晕。
2. 视觉采用清透纸白、墨黑、中性灰、松青、朱红和少量砂金。颜色不单独承担状态。
3. 常规产品控件、卡片和输入圆角不超过 8px；胶囊只用于短标签和徽章。
4. 多数交互动效为 150-280ms。S1 卡牌重排和 S9 翻面是仅有的两处标志动作，最长约 360-500ms。
5. 不使用 bounce、elastic、装饰性径向光球、持续忙碌动画或统一的页面加载编舞。
6. 复用仓库已有许可兜兜和三张主题预览 PNG。本轮不生成新吉祥物，不冻结三个未来主题的正式名称。
7. S4 不设置独立矩形“发起复盘”按钮。兜兜本身是唯一的复盘触发控件，并始终具有按钮语义和键盘路径。
8. S8 只消费真实 `TaskEvent`。事件间隔可以不规则，不能压缩成固定 6-8 秒演出。
9. S9 在所有视口保持一张纵向长笺。宽屏不拆成双页书本、正反并排页或金融仪表盘。

## 4. 全局视觉与组件契约

### 4.1 Design Tokens

全局只保留一个语义 token 来源，至少覆盖：页面、表层、次级表层和长笺表面；主、次、辅助、禁用文字；轻、强边框与持续可见焦点；`observed`、`risk`、`theme-accent`、`demo` 语义色及其浅底；4/8px 间距阶梯、固定字号阶梯、44px 图标控件、48px 主要控件；小型纸张阴影、抽屉/对话框阴影和语义 z-index；即时、快速、基础、面板、翻面时长和进入/移动/标准缓动。

组件内不得散落无归属的 hex、radius、duration 或 z-index。正文对比度至少 4.5:1，焦点、边框和大型图标至少 3:1。固定字号不随视口缩放，letter-spacing 为 0。

### 4.2 共享组件

- `DemoBadge` 支持“随机体验身份 · 示例数据”和“体验持仓 · 已编辑”两种真实来源状态；两者都不能被缩写成只有颜色的 `Demo`。
- `LockBadge` 使用统一锁图标和“暂未开放”文字。锁定详情可以操作，但锁定能力不能成为可选值。
- 每屏最多一个主要命令。图标按钮使用同一套 Lucide 线性图标并提供可访问名称和 tooltip。
- 抽屉、sheet 和 dialog 必须完成进入与退出状态，保持 focus trap、Esc、焦点返回和 reduced-motion 等价路径。
- 所有触控目标至少 44x44px；固定操作区为正文预留安全区和等高空间。

### 4.3 动效与降级

- 动效只表达进入、选择、空间层级、真实任务状态和正反面关系。
- 只动画 transform、opacity、颜色和背景色，不动画 width、height、top、left，不使用 `transition: all`。
- 退出时长约为进入的 60-70%，所有交互动效可被新输入打断。
- `prefers-reduced-motion: reduce` 或产品内减少动态开启时，取消位移、旋转、错峰和循环，只保留不超过 150ms 的交叉淡变或立即切换。
- 键盘快捷触发不播放位移动画。页面隐藏、元素离屏、任务终态或 reduced-motion 时停止循环或高资源动画。

## 5. 逐屏行为

### S0 首屏渐入

- 首次访问显示品牌标记或文字 Logo、`满懂`和`看得懂的每日持仓复盘 · 只给方向，不替你下单`。
- 正常模式约 2.3 秒后自动进入 S1；Logo 先淡入，文案在不超过 80ms 后轻微上移淡入。
- 低强调“跳过”始终可见、初始可聚焦且立即生效。开屏动画不阻塞任何输入。
- 已完成引导的回访用户只显示约 0.4 秒静态品牌短闪，然后进入 S4。
- reduced-motion 不使用位移；首次路径可短暂静态呈现，回访可以立即切换。

### S1 主题选择

- 375px 默认显示四张稳定尺寸卡牌组成的可读扇形，东方观象位于主要层级。
- 选择东方观象时，同一张卡移动到中心并适度放大，其余卡以平滑减速重新排列。卡牌不能因内容或状态改变尺寸。
- 东方观象是唯一 radio 选项；显示兜兜缩略图和“当前可用”。
- 三张锁定卡继续使用“主题预览 02/03/04”占位名称、现有独立预览图和气质短句。它们是详情按钮，不是 disabled radio；激活后只更新就近详情和“暂未开放”说明。
- 锁定卡永远不能启用下一步，不能暗示主题影响分析精度或结论。
- 键盘使用、200% 文本、reduced-motion 或布局空间不足时自动采用纵向单列，不要求用户额外切换模式。
- 768/1280px 使用四列展开，东方观象只通过位置、边框和层级获得强调，不叠加大阴影与显眼边框。

### S2 持仓来源

- 第一组标题为“先体验一次”，开放命令为“生成体验持仓”。
- 第二组标题为“使用自己的持仓”，附“即将开放”。入口为“手工录入”和“截图识别”。
- 锁定入口保持可聚焦和 `aria-disabled="true"`，激活后只显示就近说明；不打开文件选择器、表单、上传状态或成功态。
- 随机体验入口进入 S3，不直接进入主页。

### S3 随机体验身份

- 顶部持续显示随机体验身份徽章，明确数据不是用户真实资产或系统推荐约束。
- 持仓摘要展示契约中实际存在的名称、代码/类型、规模依据、观察值、观察/获取时间、来源、缓存或 fixture 状态；不能用视觉简化隐藏分析实际输入。
- 四项约束使用语义化 `dl/dt/dd`，未知／尚未决定与其他值同等展示。
- 主命令为“确认此体验身份”，次命令为“换一份体验身份”。换一份使用整块交叉淡变，不做洗牌动画。
- 用户只需一次确认，之后进入 S4。

### S4 主界面

- 页面保持单一视觉轴和开放留白，不显示行情卡、跑马灯、排行榜或仪表盘指标。
- 兜兜使用现有许可 PNG，稳定占据中央但不超过可用视口高度约 35%。当前证据/示例状态与时点使用真实数据文案。
- 整只兜兜是复盘按钮：可点击、可聚焦、支持 Enter/Space、具有可见焦点和明确可访问名称。激活后进入 S7，不直接开始分析。
- 首次进入 S4 时在兜兜附近显示一次操作提示；提示在首次触发复盘后不再常驻。即使提示消失，按钮语义、焦点和可访问名称仍保留。
- 页面不提供独立矩形复盘 CTA。持仓、历史和关于从 S5 进入。
- 移动端侧栏触发位于左下安全区，桌面位于左上工具位。两种位置使用同一导航控件与状态。
- 兜兜仅在正常动效、页面可见且位于视口内时使用不超过 4px 的低频呼吸；reduced-motion 完全静态。

### S5 侧边栏

- 导航固定为主页、仓位／身份、历史记录、关于项目；不添加账号、登录、VIP 或聊天入口。
- 主状态文案简洁标识匿名体验数据，预计删除日期始终可见。
- “工作区详情”展开后显示最后活动时间、30 天无活动后自动删除、主动删除和不可跨设备找回说明。
- 移动端宽度为 `min(85vw, 320px)`；桌面仍为 320px 抽屉，不常驻成侧栏。
- 打开时聚焦关闭按钮并锁定焦点；Esc 或遮罩关闭后焦点返回实际触发按钮。
- 抽屉与遮罩成对进入和退出。正常模式移动不超过 280ms，退出更快；reduced-motion 只淡变。

### S6 仓位／身份编辑

- 375px 使用持仓与四项约束两个可见 Tab；宽屏使用约 60:40 双栏。
- 移动摘要优先显示名称/代码、状态和观察日；按需展开观察值、来源、关联板块、规模依据和其他真实字段。
- 桌面展示完整证据核对字段，但不发展成实时行情表。当日表现只能作为次要已完成交易日信息，并同时使用文字/图标，不只靠红绿。
- 只编辑投资期限、近期流动性需求、可承受回撤和投资目标；每项保留未知／尚未决定。
- 用户第一次修改随机体验持仓或约束后，来源状态更新为“体验持仓 · 已编辑”，并在 S4/S5/S6/S9/S10 保持一致。该状态仍表示源自示例，不能变成真实持仓标签。
- 保存只影响后续快照，不改写历史。

### S7 发起复盘确认

- 375px 使用从兜兜触发关系自然进入的底部 sheet；宽屏使用不超过 420px 的 dialog。
- 内容明确当前体验来源、当前持仓与四项约束、截至最新完整交易日证据、90 秒目标和 180 秒硬截止。
- 默认焦点在“开始复盘”，Esc 取消，取消后焦点返回兜兜。
- 正常进入约 200ms、退出约 140ms；reduced-motion 直接显示或短淡变。

### S8 分析中

- 使用现有许可兜兜素材，不再使用文字圆形或通用图标占位。
- 当前真实 `TaskEvent` 显示为不超过 20 字的兜兜气泡；下方完整八阶段列表始终可见。
- 阶段包括冻结快照、解析覆盖、结构化数据、事件发现与核验、派生、结论与建议、主题叙事、保存结果。
- UI 只投影当前 `analysisId` 的真实事件并去重；不推断未报告阶段，不按固定时间推进。
- 新事件到达时进行约 220ms 交叉替换，最近状态可以降权但不能隐藏完整任务位置。
- 等待、重试、断线、离开返回、失败、180 秒终止和最终结果都有明确文字状态；当前阶段使用 `aria-live="polite"`。
- 禁止固定 1.5 秒轮播、6-8 秒模拟完成、百分比、跳过等待、假工具日志、思维链和多 agent 表演。

### S9 观象长笺

- 所有视口使用一张最大约 680px 的纵向长笺，页面滚动承担阅读进度。
- 375px 首屏应能识别日期/最新完整交易日、体验来源、分析状态、快照/覆盖、核心观察、方向性建议和风险入口；吉祥物和元数据不能把全部核心内容推到折叠线下。
- 正面和背面同时存在于同一个稳定翻面容器，使用真正连续的 Y 轴双面空间关系；不能卸载旧面后只让新面单独转入。
- “查看证据／返回观象”按钮是主路径。横向拖动只在起始意图明确横向时接管，未过阈值自然回弹，纵向滚动始终优先。
- 正反面分别保存并恢复纵向滚动位置。切换后焦点进入新面标题或返回按钮；隐藏面退出无障碍树和焦点顺序。
- reduced-motion 使用不超过 150ms 的交叉淡变或立即切换，不进行 3D 旋转。
- 正面和背面绑定同一快照、证据截止、结论、建议和版本。背面完整展示 evidence value/unit、观察/获取时间、来源、四项约束（含 `unknown`/`not_decided`）、派生关系、事件核验、缺口和限制。
- `limited` 和 `observation_only` 在首屏保持可见；`unavailable` 不渲染正常长笺。
- 宽屏只增加留白和辅助侧注，不拆成双页、并列正反面或数据仪表盘。

### S10 历史与关于

- 历史读取当前工作区真实 append-only 记录，按原快照和版本重放，不调用当前供应商重算。
- 历史项展示结果状态、快照、证据截止、体验来源和版本边界；未知版本、损坏、缺失和存储失败有明确说明与返回路径。
- 空态解释尚无复盘，并提供返回主页的可操作路径。
- 关于页说明产品定位、非投资建议、匿名私密工作区、预计删除、30 天留存、主动删除、示例/缓存和不支持跨设备找回。

## 6. 状态与来源语言

### 随机体验身份

系统刚生成、用户尚未改写的示例持仓与四项约束。界面显示“随机体验身份 · 示例数据”。

### 已编辑体验持仓

用户在随机体验基础上修改过持仓或四项约束后的来源状态。界面显示“体验持仓 · 已编辑”。它仍属于示例来源，不表示用户真实持仓，也不改变证据或分析边界。

该来源状态需要由旅程状态统一提供，不能在各屏通过文案猜测。历史记录保存分析当时的来源状态，不随之后编辑静默改写。

## 7. 现有实现事实与重点修复

- 已有共享 Button、IconButton、DemoBadge、LockBadge 和 AnalysisStatus，应扩展而不是重复实现。
- 已有完整 S0-S10 旅程、真实 TaskEvent 投影、不可变历史和公开 E2E，应保持行为契约。
- S1 当前为纵向交错卡，不是真正扇形，且没有使用三张现有主题预览素材。
- S4 当前使用 CSS 绘制兜兜并保留独立 CTA；应改为素材化的唯一兜兜触发控件。
- S5/S7 当前关闭时立即卸载，需要完整退出状态。
- S6 当前始终显示随机体验徽章，需要统一的已编辑来源状态。
- S8 当前兜兜为文字圆形占位，需要复用真实素材。
- S9 当前是旧面卸载后新面单独转入，需要稳定双面容器；背面需要补齐 evidence value/unit 和 `not_decided` 显示。

- 修改供应商、模型、分析管线、证据结构、存储期限、匿名工作区或历史语义；
- 实时行情、盘中监控、主动问答、下单、调仓或精确建议；
- 假进度、评委专用路由、隐藏 fixture 开关或第二套结果状态；
- 桌面双页书本、金融仪表盘、卡片墙、古风玄学或装饰性光球。
