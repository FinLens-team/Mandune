# 满懂 Demo V1 规格

## 1. 目标与范围

满懂面向持有基金、ETF 或 A 股的年轻轻投资者。Demo V1 在同一个公开可达的响应式应用中，让用户通过匿名私密工作区完成一次可追溯的每日复盘，并在 30 天内查看历史结果。

本规格定义可观察体验，不选择前端框架、存储引擎、认证协议、模型或部署方案。分析规则见 [`analysis-contract.md`](./analysis-contract.md)，数据供应商边界见 [`../integrations/pandaai-bocha.md`](../integrations/pandaai-bocha.md)。

## 2. 工作区与隐私

- 首次进入即创建相互隔离的匿名私密工作区，不要求注册或提供身份信息。
- 工作区在最后一次活动后保留 30 天，并显示最后活动时间和预计删除时间。期满自动删除持仓、约束、复盘与历史，且不能通过正常产品路径恢复。
- 公开应用入口不授予访问任何既有工作区的权限。工作区定位信息不得包含持仓、账户信息或模型凭据。
- 产品不承诺跨设备找回匿名工作区。用户可以在到期前主动删除工作区。

## 3. 首次使用流程

用户按以下顺序完成一条连续流程：

1. **选择主题。** 当前仅“东方观象”可用，另外三个主题只显示为锁定预览。主题只改变文字、视觉和熊猫外观，不改变计算、证据、风险状态或方向性建议。名为“兜兜”的熊猫始终是同一个角色。
2. **选择持仓来源。** 用户选择透明示例、手工录入或截图导入。三种方式都形成组合草稿并进入同一个后续流程。
3. **复核持仓。** 组合草稿在一个页面集中展示。用户可以逐行修改、删除或确认，也可以批量确认可用行。可选字段可以保留为未决未知项；资产身份或持仓规模依据无法确认的行不能冒充可用行。
4. **填写个人约束。** 投资期限、近期流动性需求、可承受回撤和投资目标均为可选项，并各自支持 `unknown/not decided`。未填写不会阻止继续，但会限制分析范围。
5. **明确生成。** 只有用户点击生成操作后，满懂才冻结本次组合快照并开始分析。导入或复核完成不能自动触发建议。
6. **观察进度。** Agent 观测台持续显示当前阶段、已确认的覆盖范围、有限重试或失败状态。用户可查看阶段详情，但不得看到模型思维链，也不能把阶段动画误认为真实完成。
7. **阅读结果。** 一次分析只产生一张可纵向阅读、可翻面的观象长笺。正面使用所选主题呈现每日复盘，理性证据背面显示同一结论的证据、未决未知项、限制和风险提示。
8. **查看历史。** 当前工作区按时间列出历史复盘。每张观象长笺绑定其组合快照、证据截止时点和生成状态，后续修改不得静默改写旧结果。

## 4. 三种持仓来源

### 4.1 透明示例

示例不要求用户提交私人数据。页面必须持续标明“示例数据”，并显示缓存 PandaAI 结构化证据及已核验事件证据的来源、观察日期、获取日期和缓存状态。示例不得把缓存值写成实时值，也不得在证据缺口下生成一张看似完整的正常观象长笺。

### 4.2 手工录入

手工录入先形成组合草稿。基金、ETF 和 A 股均可录入；无法识别或暂不支持的资产继续显示为未决未知项或不支持，不得从复核页或覆盖率中静默消失。

### 4.3 截图导入

上传前，页面说明截图将交给多模态模型提取，并可能包含敏感金融信息。模型输出只能形成组合草稿，不能自动确认。

原始截图在提取完成、失败或中止后删除，不进入历史、分析证据、默认日志、分析事件、公开资源或测试快照。后续流程只使用用户复核后的结构化持仓。提取不完整时，已识别的组合草稿保留，未决未知项保持未知，并继续提供手工修正路径。

## 5. 观象长笺

观象长笺正面优先回答：持仓相关的主要变化、组合含义以及用户下一步应关注或调整的方向。理性证据背面至少包含：

- 本次确认的完整结构化持仓及覆盖状态；
- 四项约束及其未知状态；
- 主要结论与对应证据引用；
- 结构化市场数据的观察时间和获取时间；
- 证据截止时点，以及事件证据的来源、发布时间和核验状态；
- 缺失、过期、冲突、不支持或无法核验的数据及其影响；
- 方向性建议的触发依据；
- 用户保留最终判断和操作权的风险提示。

建议只能表达维持、暂停增加、降低某类暴露、调整关注或配置方向等定性方向。不得给出精确金额、份额、比例、价格、买卖时点、收益保证或代客操作。

## 6. 时点与时限

- 结构化行情和净值以分析开始时可获得的最新完整交易日为基准，不承诺盘中或实时数据。
- 事件可以晚于该交易日发布，但必须显示实际发布时间，且不能被倒写成该交易日已经发生的市场事实。
- 实时分析以 90 秒内完成为目标。到 180 秒必须终止仍未完成的外部调用和生成步骤；已有证据足够时返回有限分析，否则返回分析不可用。超时不得产生正常观象长笺。
- 透明示例可以使用预先缓存的证据，但必须暴露缓存状态和截止日期。

## 7. 降级与恢复

| 情况 | 可观察结果 | 恢复路径 |
|---|---|---|
| 截图模糊、缺行或提取失败 | 不自动确认；受影响字段保留为未决未知项 | 重新上传或手工录入 |
| 资产身份含糊 | 行保持待复核，不附会行情 | 用户选择或修改资产 |
| 市场数据缺失、过期或冲突 | 缩小受影响结论并标明覆盖缺口 | 稍后重试或继续有限分析 |
| 四项约束缺失 | 允许生成，但相关个性化判断受限 | 补充约束后生成新快照 |
| 模型、供应商或网络失败 | 不显示正常观象长笺 | 有证据时有限分析，否则明确失败并允许重试 |
| 达到 180 秒 | 停止生成，显示有限或不可用状态 | 保留快照并允许重试 |

## 8. 验收标准

- 新用户能在同一公开应用内依次完成主题选择、任一持仓导入方式、单页复核、可选约束、明确生成、Agent 观测台、观象长笺翻面和历史查看。
- 两个匿名私密工作区不能互相访问；页面显示最后活动时间和预计删除时间，连续 30 天无活动后其持仓、约束、复盘与历史均被删除。
- “东方观象”可选择，三个主题清楚标记为锁定预览；兜兜在所有预览中保持名称、身份和基础外形可识别。
- 批量确认不会隐藏未决未知项，也不会把资产身份或持仓规模依据不明的行变成可用行。
- 四项约束可以全部保持未知并继续生成；结果明确说明因此受限的判断。
- 截图路径证明原图在成功、失败和中止后均已删除，历史和默认日志中只保留复核后的结构化数据。
- 示例路径持续标明示例与缓存状态，并能从卡片翻面核对缓存证据的来源和日期。
- 正常结果只有一张观象长笺；正面与理性证据背面引用同一组合快照、证据截止时点、结论和方向性建议。
- 任一物质性结论都能追溯到确认输入、派生结果或经核验的带日期证据。
- 供应商或模型失败会产生有限分析或不可用状态，不会制造当前值或正常观象长笺。
- 实时路径记录 90 秒目标和 180 秒硬截止；硬截止后没有仍在运行的生成任务。
- 历史卡不会因持仓、约束、主题或外部数据后来变化而静默改变。
- 在 375px 触控视口中，核心流程不依赖 hover、动画、截图上传或主题解锁。

## 9. 非目标

- 主动查询、自由追问或聊天式投资问答；
- 券商连接、账户验证、自动同步、下单或调仓；
- 盘中监控、实时行情、价格预测或收益承诺；
- 三个锁定主题的完整实现；
- 匿名工作区的长期归档、跨设备恢复或社交分享。
