# 满懂 Demo V1 规格

## 1. 目标与范围

满懂面向持有基金、ETF 或 A 股的年轻轻投资者。Demo V1 在同一个公开可达的响应式应用中，让用户通过匿名私密工作区完成一次可追溯的每日复盘，并在 30 天内查看历史结果。

本规格定义可观察体验与 Demo 交付形态。分析规则见 [`analysis-contract.md`](./analysis-contract.md)，数据供应商边界见 [`../integrations/pandaai-bocha.md`](../integrations/pandaai-bocha.md)，屏幕索引与实现映射见 [`demo-v1-frontend-flow.md`](./demo-v1-frontend-flow.md)。

## 2. 工作区与隐私

- 首次进入即创建相互隔离的匿名私密工作区，不要求注册或提供身份信息。
- 工作区在最后一次活动后保留 30 天，并显示最后活动时间和预计删除时间。期满自动删除持仓、约束、复盘与历史，且不能通过正常产品路径恢复。
- 公开应用入口不授予访问任何既有工作区的权限。工作区定位信息不得包含持仓、账户信息或模型凭据。
- 产品不承诺跨设备找回匿名工作区。用户可以在到期前主动删除工作区。
- 首次引导完成状态可用工作区维度的本地标记（如 `mandong.onboarded`）判断；已引导用户可跳过引导屏直接进入主界面。

## 3. Demo V1 可观察屏幕流

用户按下列屏幕完成闭环。每个动效步骤都必须有不依赖动画、悬停或横向手势的等价路径。

### S0 首屏渐入

- 每次进入可展示；已引导用户可尽快进入主界面。
- 屏幕正中品牌与一句话介绍；提供可聚焦「跳过」。
- 约 2–3 秒自动过渡；减少动态效果时静态呈现约 0.4 秒后进入下一步。

### S1 主题选择（仅首次引导）

- 当前仅「东方观象」可选；另三个主题为锁定预览。
- 主题卡展示该主题吉祥物：东方观象为兜兜；其余为占位形象与占位名。
- 锁定主题可查看细节，但不可作为「下一步」选择；须有「暂未开放」可见标签。
- 「下一步」仅在已选东方观象时可用。

### S2 持仓来源选择（仅首次引导）

Demo 交付形态：

| 入口 | Demo 状态 |
|---|---|
| 随机生成一份体验持仓 | **开放**，进入 S3 |
| 手动录入持仓 | **暂未开放**占位，点击提示，不跳转 |
| 截图识别导入 | **暂未开放**占位，点击提示，不上传真实截图 |

占位按钮须有可见「即将开放」标签与正确的禁用语义，不能只靠灰色。

### S3 随机体验身份（只读摘要）

- 展示随机生成的体验持仓与四项约束摘要。
- **全程标注「随机体验身份」**，不得看起来像用户真实选择或系统默认约束。
- 随机持仓从「PandaAI 可解析且已有缓存证据」的 A 股/ETF 候选池抽取，保证后续可真跑或诚实缓存兜底。
- 持仓字段可含：名称、净值/观察值、当日收益、关联板块、持有收益、观察日期；全部为 observed/derived，须标注观察/获取时间，不冒充实时。
- 确认了解后进入主界面；进入主界面后同一「仓位/身份」页可编辑。

### S4 主界面

- 正中为当前主题吉祥物（东方观象=兜兜）；左下角唤出侧边栏。
- 点击吉祥物须经二级确认后才发起分析。
- 不做通用金融仪表盘或行情小卡拼接首页。

### S5 左侧边栏

布局参考可折叠导航抽屉（顶部品牌与关闭、中部导航、底部工作区状态）：

- 主页
- 仓位 / 身份
- 历史记录
- 关于项目
- 其它概念入口一律「暂未开放」
- 底部：最后活动时间、预计删除时间、「减少动态效果」等可访问性入口；无账号登录

### S6 仓位 / 身份（可编辑）

- 与 S3 同一页面的可编辑态：持仓行增删改、四项约束编辑。
- 约束每项可选具体值或「未知／尚未决定」。
- 修改后作为后续分析输入；产生新快照，不改写历史复盘。
- 继续标明随机体验身份来源，直到用户明确改写。

### S7 发起复盘确认

- 确认文案说明将按当前持仓与约束分析，约需 90 秒。
- 取消 / 开始复盘；Esc 取消；默认焦点在开始。

### S8 分析中（单 agent · 聊天气泡）

- **Demo 编排形态为单个 agent 串行**，不是多 agent 编排团队。
- 可观察阶段仍须来自真实任务状态：结构化数据 → 事件搜索 → 事件核验 → 可复算派生 → 结论/建议 → 主题叙事。
- 气泡展示当前阶段与工具目的短句（建议 ≤20 字）；不得展示思维链；不得纯计时器伪造进度。
- 90 秒目标、180 秒硬截止；允许离开后返回。

### S9 每日复盘报告

- 正面：所选主题叙事 + 该主题吉祥物；回答主要变化、组合含义、方向性建议。
- 背面：同一版本理性证据（快照、时点、覆盖、约束、结论引用、观察/获取时间、事件核验、缺口、建议触发依据、风险提示）。
- 横向拖动三维翻面 + 「查看证据／返回观象」按钮；手势不得劫持纵向滚动。

### S10 历史与关于

- 历史：按时间列出本工作区复盘；绑定快照、证据截止时点与生成状态；不可静默改写。
- 关于：产品定位、不构成投资建议、隐私与 30 天工作区说明。

## 4. 持仓来源与数据策略

### 4.1 随机体验（Demo 主路径）

- 不要求用户提交私人数据。
- 必须持续标明随机体验 / 示例或缓存状态。
- 真实优先：在时限内尝试真实结构化数据与事件路径；输出须通过版本化结构与内容边界校验。
- 诚实兜底：未接通、超时或校验失败时，回退到**同一批资产**的缓存证据（`src/fixtures` 或等价缓存），暴露来源、观察时间、获取时间、缓存状态；不得把缓存写成实时，不得把示例结论套到不同持仓。

### 4.2 手工录入与截图（产品能力，Demo 占位）

- 产品契约仍允许手工与截图草稿路径。
- **Demo V1 交付中二者为「暂未开放」占位**，用于体现能力边界与工期取舍；实现不得上传真实截图，不得假装导入成功。

## 5. 每日复盘报告内容

报告正面优先回答：持仓相关主要变化、组合含义、下一步可关注或调整的方向。理性证据背面至少包含：

- 本次确认的完整结构化持仓及覆盖状态；
- 四项约束及其未知状态；
- 主要结论与对应证据引用；
- 结构化市场数据的观察时间和获取时间；
- 证据截止时点，以及事件证据的来源、发布时间和核验状态；
- 缺失、过期、冲突、不支持或无法核验的数据及其影响；
- 方向性建议的触发依据；
- 用户保留最终判断和操作权的风险提示。

建议只能表达定性方向。不得给出精确金额、份额、比例、价格、买卖时点、收益保证或代客操作。

## 6. 时点与时限

- 结构化行情和净值以分析开始时可获得的最新完整交易日为基准，不承诺盘中或实时数据。
- 事件可以晚于该交易日发布，但必须显示实际发布时间。
- 实时分析以 90 秒内完成为目标。到 180 秒必须终止仍未完成的外部调用和生成步骤；已有证据足够时返回有限分析，否则返回分析不可用。超时不得产生复盘报告。
- 缓存/示例路径必须暴露缓存状态和截止日期，不得计入「实时供应商可用」的证明。

## 7. 降级与恢复

| 情况 | 可观察结果 | 恢复路径 |
|---|---|---|
| 随机资产证据缺失/过期/冲突 | 缩小结论并标明覆盖缺口；或诚实缓存兜底 | 重试或继续有限分析 |
| 四项约束未知 | 允许生成，相关个性化判断受限 | 在仓位/身份页补充后生成新快照 |
| 模型、供应商或网络失败 | 不显示复盘报告；可 limited / observation_only / unavailable | 有证据时有限分析，否则明确失败并允许重试 |
| 达到 180 秒 | 停止生成，显示有限或不可用状态 | 保留快照并允许重试 |
| 暂未开放入口 | 可见占位提示，不跳转、不假装成功 | 使用随机体验路径 |

## 8. 验收标准

- 新用户能在桌面与 375px 完成：S0→S1→S2→S3→S4→S7→S8→S9，并打开历史/关于。
- 已引导用户可跳过 S1/S2 进入主界面。
- 全流程存在不依赖 hover、动画、横向手势、截图上传或主题解锁的纯键盘路径；减少动态效果开关生效。
- 两个匿名私密工作区不能互相访问；显示最后活动与预计删除时间。
- 「东方观象」可选；三个主题锁定预览清楚标记；兜兜仅作为东方观象吉祥物可识别。
- 随机体验身份全程标注；四项约束可全未知并仍能发起分析，结果说明受限判断。
- 分析 90 秒目标 / 180 秒硬截止有记录；硬截止后无仍运行任务；失败不伪造复盘报告。
- 正面与背面引用同一快照、截止时点、结论与建议；物质性结论可追溯；`observed` / `derived` / `generated` 可区分。
- 主题与吉祥物切换不改变理性结论、证据、覆盖、风险与建议。
- 日志、分析事件与公开页面不含原始截图、身份、账户或凭据。
- 手工录入与截图入口在 Demo 中仅占位，不形成虚假导入成功。

## 9. 非目标

- 主动查询、自由追问或聊天式投资问答；
- 券商连接、账户验证、自动同步、下单或调仓；
- 盘中监控、实时行情、价格预测或收益承诺；
- 三个锁定主题的完整实现与真实多吉祥物最终美术（Demo 可用占位）；
- Demo 阶段完整手工录入与真实截图上传闭环；
- 多 agent 编排团队作为 Demo 默认分析形态；
- 匿名工作区的长期归档、跨设备恢复或社交分享。
