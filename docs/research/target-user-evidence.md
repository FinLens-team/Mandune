# 满懂目标用户证据计划

状态：`研究计划，尚无可声明的访谈或可用性结论`。

本文把产品假设、比赛方问题和真实用户证据分开。除非下方证据登记表加入可审计记录，否则提交材料不得声称“用户普遍认为”“年轻人都需要”或引用虚构访谈。

## 当前已知

当前产品契约把目标用户定义为年轻轻投资者：以基金、ETF 为主要持仓，可能持有少量 A 股；愿意复盘，但不使用专业机构工作流；希望先理解结论，也能继续核对依据。

这是已确认的产品范围，不是经用户研究证明的人群规模或需求强度。度小满赛道要求说明目标用户痛点及判断依据，也不等于比赛方替项目提供了用户证据。

## 尚未证实的核心假设

| ID | 假设 | 可能推翻它的观察 | 所需证据 |
|---|---|---|---|
| `H-01` | 目标用户的主要困难是把分散信息与自己的持仓联系起来，而不是缺少更多资讯 | 用户能稳定完成现有工具复盘，或主要需求是交易执行/实时行情 | 问题访谈、现有流程回放、替代工具对照 |
| `H-02` | 用户愿意确认完成复盘所需的持仓，并填写四项约束或明确选择 `unknown` | 用户认为复核成本或隐私风险高于复盘价值 | 首次使用观察、放弃点、隐私顾虑原话 |
| `H-03` | 观象长笺的东方观象叙事正面能降低首次理解负担 | 用户看完仍不能说出主要变化、与持仓的关系和下一步关注方向 | 限时理解任务、复述准确性、误解记录 |
| `H-04` | 理性证据背面能提高可核对性，而不会成为无人使用的附录 | 用户找不到三维翻面和按钮替代、看不懂证据字段，或不关心依据 | 查证任务成功率、翻面行为、追问原因 |
| `H-05` | Agent 观测台能帮助用户理解结论如何形成 | 用户把阶段、覆盖或等待误解为预测可靠度，或观测台只增加认知负担 | 状态解释任务、信任校准访谈、误读记录 |
| `H-06` | 用户能理解缓存证据的时点和非实时性质 | 用户把获取时间当市场时间，或把缓存值当当前报价 | 时间字段辨认任务、口头解释、错误分类 |
| `H-07` | 有限态能让用户理解“哪些结论暂时不能下” | 用户把有限态理解为系统故障、保守推荐或市场安全信号 | 正常态/有限态对照任务、结论边界复述 |
| `H-08` | 方向性建议足以支持下一步判断，不需要精确交易指令 | 用户只有在获得具体金额、比例、价格或时点时才感到有价值 | 建议效用访谈、后续动作分类、越界需求记录 |
| `H-09` | 30 天工作区历史能帮助用户区分旧复盘与当前状态 | 用户把旧记录当作当前建议，或无法定位其快照和证据截止时点 | 历史辨认任务、版本与时点复述 |
| `H-10` | 固定熊猫角色兜兜能跨主题保持可识别身份，并帮助用户接受未知 | 用户把不同服饰的兜兜当成不同角色，或把它的表达理解为吉凶预测和替用户决策 | 跨主题识别任务、职责复述、越界误读记录 |

## 招募范围

优先招募符合以下条件的参与者：

- 目前或近期持有基金、ETF，可能持有少量 A 股；
- 会查看净值、涨跌或市场信息，但不是专业投研或机构从业者；
- 有过“需要判断是否继续持有、增加关注或降低暴露”的复盘经历；
- 愿意使用虚构或自行脱敏的示例组合完成任务。

不要要求参与者提交真实账户截图、完整账户号、身份证明、交易凭据或可识别的真实持仓金额。研究不以是否采纳建议或实际交易结果作为参与条件。

建议首先覆盖不同经验水平和复盘频率。样本数量只能在实际完成后填写，不能用计划人数作为“已访谈人数”。

## 第一轮研究任务

### 任务 A：现有复盘流程

让参与者回忆最近一次真实复盘，用自己的话描述：触发原因、查看的信息、如何判断与持仓相关、哪里卡住、最后是否形成行动方向。研究者不先介绍满懂，避免把产品结构塞进回答。

### 任务 B：首次使用

使用版本化透明示例，请参与者从普通入口完成东方观象主题选择、组合草稿单页复核、可用行确认、四项可选约束与 `unknown`、显式生成组合快照。记录其是否理解示例/缓存标识、锁定主题、未知项和快照后果。若需要提示，记录提示发生的位置和内容。

### 任务 C：观象长笺

给参与者限定阅读时间，然后请其复述：今天最重要的变化、为什么与组合有关、建议停留在哪个方向、有哪些限制。不要问“你觉得这个设计好吗”来代替理解任务。

### 任务 D：理性证据背面

指定东方观象叙事正面的一项重要结论，请参与者先横向拖动三维翻面，再使用“查看证据”按钮进入理性证据背面，找到其确认输入、证据时点、派生关系和未知项，并判断该证据是观察、派生还是生成解释。

### 任务 E：Agent 观测台

请参与者指出当前真实阶段、覆盖数量、等待或失败状态、哪个结果来自缓存、一个失败会影响哪项结论。观察其是否把 Agent 活跃度、数量或等待动画当成预测正确性保证。不要展示或要求解释思维链。

### 任务 F：有限态

从普通路线运行证据缺失或过期的示例。请参与者说明：现在仍能确认什么、不能下什么结论、下一步可以补什么信息。禁止用隐藏评委路线或开发工具切换状态。

### 任务 G：工作区历史

打开 30 天工作区历史中的当前和旧复盘，请参与者指出各自绑定的组合快照、证据截止时点和分析状态，并判断旧记录是否仍代表当前状态。

### 任务 H：兜兜的身份与职责

依次展示兜兜在东方观象和另一主题中的服饰与环境，请参与者判断是否为同一角色，并复述它能做和不能做的事。记录参与者是否理解兜兜只负责观察、解释和承认未知，不预测吉凶，也不替用户决定。

## 最低可观察指标

以下是研究应记录的字段，不是当前成绩：

- 首次使用完成或放弃，以及放弃步骤；
- 每项任务是否独立完成、提示后完成或未完成；
- 参与者对主要结论、证据时点、未知项和建议边界的原话复述；
- 把缓存当实时、把派生当观察、把有限态当安全信号等关键误解；
- 找到三维翻面和“查看证据”按钮替代的时间和路径；
- Agent 观测台带来的具体帮助或负担；
- 对输入持仓、约束和外部处理的隐私顾虑；
- 参与者希望采取的下一步，以及是否要求产品越过精确交易指令边界；
- 能否区分 30 天历史中的旧快照、旧证据截止时点和当前状态。
- 能否跨主题识别兜兜，并准确复述其观察、解释、承认未知和不替用户决策的边界。

研究结束后再设定或报告通过率。小样本定性结果只能描述观察到的问题和模式，不能外推人群比例。

## 访谈提纲

1. 你最近一次查看持仓是因为什么？
2. 当时依次看了哪些信息？哪些信息最终影响了你的判断？
3. 你怎么判断一条市场信息与自己的持仓有关？
4. 有没有因为信息太多、相互冲突或过期而放弃判断？请描述具体一次。
5. 你愿意向复盘工具提供哪些信息？哪些信息不会提供？
6. 看到方向性建议时，你需要什么依据才会继续考虑？
7. 数据不足时，你希望工具做什么？什么表现会让你误以为它仍然掌握完整信息？
8. 哪些内容应该由系统完成，哪些判断必须由你自己保留？

避免诱导问题，例如“可追溯证据是不是让你更信任”“东方风格是不是更容易理解”。先让参与者完成任务和自由表达，再追问原因。

## 提交可用口径

在没有真实研究证据前，可以写：

> 满懂当前面向以基金和 ETF 为主的年轻轻投资者。我们把“难以把分散信息与自己的持仓和约束联系起来”作为待验证的核心问题，并已定义首次使用、观象长笺理解、理性证据背面查找、Agent 状态解释和有限态辨认任务。

只有登记真实证据后，才可以写：

> 在 `[日期]` 对 `[实际人数与招募范围]` 完成 `[方法]`。参与者在 `[具体任务]` 中出现 `[可观察现象]`；该结果支持或削弱 `[假设 ID]`，但受 `[样本与方法限制]` 约束。

不得写：

- “采访显示年轻人普遍不会理财”，除非有可审计证据且样本支持该外推；
- “用户更信任多 Agent”，如果只展示了界面偏好；
- “用户会因此减少亏损”，如果没有长期、合规且可归因的结果研究；
- “用户喜欢东方观象”，如果没有比较任务和原始反馈；
- 任何虚构姓名、引语、人数、百分比、留存或交易效果。
