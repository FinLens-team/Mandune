# 满懂 Demo V1 视觉与动效规格

状态：`Accepted for implementation`。本文件是 S1-S10 的视觉与交互实现基准，S0 已移除；产品行为以 [`../../PRODUCT.md`](../../PRODUCT.md) 和 [`../specs/demo-v1.md`](../specs/demo-v1.md) 为准，分析状态以 [`../specs/analysis-contract.md`](../specs/analysis-contract.md) 为准。

## 1. 方案取舍

本规格综合两份 Gemini 设计提案，但不原样采用任一版本：

- 以第一版的克制纸墨体系、语义色和逐屏骨架为基础；
- 吸收第二版更清楚的响应式断点、侧栏结构、焦点管理和复盘报告信息层级；
- 舍弃两版中与产品契约冲突或不适合工具界面的内容。

明确不采用：

- 按固定秒数播放的分析进度、6-18 秒模拟完成或「跳过等待」；
- `止损线`、`调仓纪律`等不属于四项最小约束的字段；
- 精确调仓比例、买卖点、收益预测或预测置信度；
- 黄历干支日期、「今日宜复盘」、吉凶、卦象或算命式视觉；
- 未经确认的锁定主题正式名称与吉祥物名称；
- 「页面关闭即清空」或「仅本地会话缓存」等错误工作区说明；
- 假上传、假实时、假 K 线、粒子流、伪代码流和进度百分比；
- S9 桌面双页仪表盘、卡片嵌套和装饰性径向光晕；
- disabled 控件仍可点击、自动振动或依靠抖动表达错误。

## 2. 场景与设计原则

使用场景：用户在通勤、午休或晚间复盘时，用手机或桌面浏览器安静阅读一次与体验持仓相关的证据整理；界面应先让人确认「这是什么数据、截至何时、当前能判断什么」，再表现主题气质。

1. **证据先于装饰**：状态、时点、未知和恢复路径始终比吉祥物与材质更醒目。
2. **开放页面优于卡片墙**：用分区、留白、对齐和细线组织内容；卡片只用于可选择对象、模态和独立重复项。
3. **单一主操作**：每屏只有一个主要 CTA；图标按钮使用 Lucide 或同一套线性图标，并提供可访问名称和 tooltip。
4. **克制东方感**：东方感来自留白、排版、观测刻度和少量金色识别，不来自仿古、黄历或神秘主义。
5. **状态不依赖颜色**：青绿、朱红、靛蓝都必须配合文字和图标。
6. **动效表达因果**：只表现进入、选择、层级、任务状态和正反面空间关系；不制造忙碌感。

## 3. Design Tokens

### 3.1 色彩

```css
:root {
  color-scheme: light;

  --color-bg-base: #f3f5f2;
  --color-bg-surface: #ffffff;
  --color-bg-subtle: #edf1ee;
  --color-bg-letter: #fffefa;

  --color-text-primary: #171a18;
  --color-text-secondary: #535b56;
  --color-text-tertiary: #69716c;
  --color-text-disabled: #8a928d;

  --color-border-subtle: #d7ddd9;
  --color-border-strong: #aeb8b2;

  --color-observed: #176b62;
  --color-observed-bg: #e3f2ee;
  --color-risk: #923d36;
  --color-risk-bg: #fff2ef;
  --color-theme-accent: #a77728;
  --color-demo: #365f8d;
  --color-demo-bg: #e9f0f7;
  --color-focus: #0a4d47;

  --color-overlay: rgb(23 26 24 / 48%);
}
```

使用规则：

- `observed` 只表示已核对、可观察或当前阶段，不表示上涨；
- `risk` 只表示风险、冲突、未知或需处理状态，不表示下跌；
- `theme-accent` 的可见面积不超过单屏约 5%，不用作正文或主要按钮文字；
- `demo` 专门标识随机体验身份，避免与证据状态混用；
- 正文与背景对比度至少 4.5:1，焦点、边框和大型图标至少 3:1；
- 颜色不能成为唯一状态信号。

- 所有触控目标至少 44x44px，主要按钮高度 48px。
- 固定底栏必须为正文预留 `safe-area-inset-bottom` 和等高内边距。

```css
:root {

    "Microsoft YaHei", system-ui, sans-serif;
  --font-serif: "Source Han Serif SC", "Noto Serif SC", "Songti SC", serif;

  --font-size-2xl: 28px;

```

- 产品 UI 使用固定字号，不随视口宽度缩放；letter-spacing 固定为 `0`。
- 标题、按钮、标签、数据和正文默认使用 `--font-sans`。
- `--font-serif` 仅用于 S9 笺头和一级章节标题，正文仍使用无衬线字体。
- 正文 16/26px，辅助文字最低 12/18px；桌面长文控制在 60-75ch。

### 3.4 边框、阴影与焦点

```css
:root {
  --shadow-paper: 0 2px 8px rgb(23 26 24 / 6%);
  --shadow-overlay: 0 12px 28px rgb(23 26 24 / 14%);
  --focus-ring: 0 0 0 3px rgb(10 77 71 / 28%);
}
```

- 普通区段用边线或留白，不加阴影。
- 复盘报告可使用 `--shadow-paper`，抽屉和对话框使用 `--shadow-overlay`。
- 不在同一普通卡片上叠加显眼边框与大阴影。
- `:focus-visible` 必须始终可见，不能仅改变背景色。

### 3.5 动效

```css
:root {
  --duration-instant: 100ms;
  --duration-fast: 150ms;
  --duration-base: 220ms;
  --duration-panel: 280ms;
  --duration-flip: 360ms;

  --ease-enter: cubic-bezier(0.22, 1, 0.36, 1);
  --ease-move: cubic-bezier(0.25, 1, 0.5, 1);
  --ease-standard: cubic-bezier(0.65, 0, 0.35, 1);
}
```

- UI 动效只改变 `transform`、`opacity`、颜色或背景色，不动画 `width`、`height`、`top`、`left`。
- 退出比进入快约 30%；所有交互动效可被新输入打断。
- 不使用 bounce/elastic；主题卡展开也使用平滑减速曲线。
- `prefers-reduced-motion: reduce` 或产品内「减少动态效果」开启时，取消位移、旋转、错峰和循环，仅保留不超过 150ms 的交叉淡变或立即切换。
- 键盘快捷操作不播放位移动画。

## 4. 全局组件

### LockBadge

- 文案：`暂未开放`；使用 `Lock` 图标与文字。
- 锁定主题仍可聚焦查看说明，但不能成为下一步选择。
- 手工和截图入口使用 `aria-disabled="true"`，激活时只显示说明，不打开文件选择器或表单。

### Button

- Primary：墨黑底、白字、48px 高、8px 圆角；每屏最多一个。
- Secondary：白底、强边框、墨黑字。
- Icon：44x44px，使用统一 20px 线性图标。
- Disabled：正确 `disabled` 或 `aria-disabled` 语义，无按压、抖动、振动或页面跳转。
- Loading：保留原宽度，显示状态文字；不得只显示无名称 spinner。

### Drawer

- 顶部品牌与关闭，中部导航，底部工作区状态与减少动态效果。
- 移动端宽度 `min(85vw, 320px)`；桌面端 320px。
- 打开时焦点进入关闭按钮并启用 focus trap；Esc 关闭后焦点返回触发按钮。
- 滑入 280ms；减少动态效果时 100-150ms 淡入或立即显示。

### AnalysisStatus

- 同时显示状态文本、图标和必要说明。
- 支持 `supported`、`limited`、`observation_only`、`unavailable`。
- `limited` 和 `observation_only` 仍必须在 S9 首屏保持可见；`unavailable` 不渲染复盘报告。

## 5. 逐屏规格

### S0 已移除

- 不渲染独立品牌开屏、定时过渡或「跳过」按钮。
- 匿名工作区准备完成后，首次访问直接显示 S1；回访直接显示 S4。

### S1 主题选择

- **目标**：展示主题表现差异，同时明确只有东方观象可选。
- **375 默认**：四张稳定尺寸主题卡形成可读扇形，东方观象居中置顶；选择后同一张卡移动居中并适度放大，其余卡平滑重排；下方保留明确「选择东方观象」按钮。
- **375 降级**：纵向单列；减少动态效果、键盘使用或内容放大时直接采用此布局。
- **768/1280**：四列并排，最大宽度 960px；锁定卡降低强调但保持可读对比。
- **内容**：东方观象显示现有许可兜兜素材；其它三张使用现有主题预览 PNG 和 `主题预览 02/03/04` 占位名称，不新增正式名称。
- **动效**：卡片用 transform 在 280ms 内重排，不弹跳；锁定项激活时只更新就近说明。
- **无障碍**：可选项使用 radio 语义；锁定预览使用按钮或详情控件，不伪装成可选 radio。

### S2 来源选择

- **目标**：以最低阻力进入随机体验，诚实展示未开放边界。
- **375**：标题、随机体验主入口、分隔说明、手工/截图两个占位入口纵向排列。
- **768/1280**：最大宽度 720px；随机入口占主要宽度，两个占位入口可并列。
- **分组与主文案**：第一组 `先体验一次`，主命令 `生成体验持仓`；第二组 `使用自己的持仓`并标注 `即将开放`。
- **占位**：`手工录入持仓`、`截图识别导入`均带 LockBadge；激活后行内说明，不弹自动消失 Toast。
- **禁止**：不调用文件选择器，不展示上传进度或成功态。

### S3 随机体验身份

- **目标**：让用户确认这是一份非真实、可继续使用的体验输入。
- **375**：持仓摘要使用连续列表；四项约束使用 `dl`；底部固定确认栏。
- **768/1280**：最大宽度 920px，可将持仓与约束分为 3:2 两栏，但保持先持仓后约束的阅读顺序。
- **持仓字段**：名称、资产类型/代码、持仓规模依据、观察值或净值、当日已完成交易日表现、关联板块、观察日期及缓存/来源状态。字段只显示契约中存在且有 observed/derived 来源的内容。
- **四项约束**：投资期限、近期流动性需求、可承受回撤、投资目标；`未知／尚未决定`按普通有效值展示。
- **操作**：Primary `确认此体验身份`；Secondary `换一份体验身份`。换一份时整块内容交叉淡变，不做洗牌表演。
- **禁止**：不隐藏必要的组合输入，不把体验约束写成系统推荐值。

### S4 主界面

- **目标**：提供安静的复盘入口，不形成行情仪表盘。
- **375**：兜兜与当前证据状态位于中央；侧栏图标放在左下拇指可达区；主要操作在底部安全区上方。
- **768/1280**：内容保持单一主轴，兜兜不超过可用视口高度的 35%；最近一次复盘时间可作为次要文本，不新增指标卡。
- **操作**：`发起今日复盘`打开 S7；点击兜兜触发同一确认路径。Secondary `查看持仓与约束`进入 S6。
- **动效**：兜兜可有 3-4 秒、位移不超过 4px 的低频呼吸；页面隐藏、离屏或减少动态时停止。背景不使用渐变光球。
- **状态文案**：只根据真实证据准备状态显示，不写「已更新」除非已有对应状态与时点。

### S5 侧边栏

- **导航**：主页、仓位／身份、历史记录、关于项目；其它概念入口如存在必须标 `暂未开放`。
- **底部状态**：主文案简洁标识匿名体验数据，预计删除日期始终可见；可展开 `工作区详情`显示最后活动时间、`30 天无活动后自动删除`、主动删除和不可跨设备找回；无账号、头像、手机号或登录入口。
- **375**：覆盖宽度 `min(85vw, 320px)`，遮罩保留关闭路径。
- **768/1280**：仍使用 320px 抽屉；不默认常驻，以免破坏主界面单一焦点。
- **动效与焦点**：遵循全局 Drawer；遮罩与抽屉成对进退。

### S6 仓位／身份编辑

- **目标**：查看并修改下一次分析的完整输入，不呈现交易终端。
- **375**：持仓与四项约束使用两个可见 Tab；底部保存栏不遮挡内容。
- **768/1280**：最大宽度 920px；可采用左右两栏，持仓列表占 60%，约束占 40%。
- **持仓**：沿用已实现的草稿、可用行、未知字段和确认保护；每行不嵌套卡片。
- **约束**：只编辑投资期限、近期流动性需求、可承受回撤、投资目标；每项必须提供 `未知／尚未决定`。使用 radio/select/input，不用无刻度滑杆猜测数值。
- **保存**：修改形成后续新快照，不改写历史；继续标注体验来源，直到用户明确改写相关内容。
- **来源状态**：用户第一次修改随机持仓或四项约束后，S4/S5/S6/S9/S10 统一显示 `体验持仓 · 已编辑`；它仍是示例来源，不冒充真实持仓。
- **禁止**：不新增止损线、调仓纪律、风险测评结论或自动建议值。

### S7 发起复盘确认

- **目标**：确认当前输入、证据边界和耗时预期。
- **375**：从发起按钮位置关联出现的底部 sheet；宽屏为不超过 420px 的居中 dialog。
- **内容**：当前为随机体验身份；依据当前持仓与四项约束；使用截至最新完整交易日的证据；目标约 90 秒，180 秒硬截止。
- **操作**：Secondary `取消`；Primary `开始复盘`。默认焦点按产品规格进入开始按钮，Esc 取消。
- **动效**：200ms 入场、140ms 退场；减少动态时直接显示。

### S8 分析中

- **目标**：解释单个分析 agent 的真实任务状态，不表现思维过程。
- **375 动态态**：使用现有许可兜兜 PNG；兜兜上移；当前阶段气泡不超过 20 字；下方保留完整八阶段列表，最近两条已完成状态可降权显示。
- **纯文字态**：直接显示阶段列表、当前状态、覆盖、等待、重试或失败；它也是 reduced-motion 与无插画时的完整路径。
- **768/1280**：最大宽度 640px；气泡与阶段列表仍沿单一纵向轴排列。
- **阶段来源**：冻结快照、解析覆盖、结构化数据、事件发现与核验、派生、结论与建议、主题叙事、保存结果。UI 只消费真实 task event。
- **动效**：只有收到新事件时，当前气泡 220ms 交叉替换；不设固定轮播间隔，不显示百分比，不提供跳过等待。
- **时限**：90 秒是目标，180 秒是硬截止；超时后进入有限或不可用状态，停止循环动画和未完成任务。
- **无障碍**：当前阶段使用 `aria-live="polite"`；阶段历史可正常浏览，不用 `assertive` 连续打断。

### S9 每日复盘报告

- **目标**：先读懂主题叙事，再核对同一版本理性证据。
- **375**：单份纵向复盘报告；顶部工具栏只保留 `查看证据／返回观象`与关闭/返回；正文正常页面滚动。
- **768/1280**：报告最大宽度 680px，保持单一阅读主轴；辅助元数据可作侧注，但不拆成双页或仪表盘。
- **首屏顺序**：日期与最新完整交易日、分析状态、组合快照、覆盖、核心观察、方向性建议和可见风险提示。
- **正面**：东方观象叙事与兜兜；不得新增事实或弱化未知。
- **背面**：确认输入、四项约束（含 `unknown`/`not_decided`）、证据 value/unit、观察/获取时间、来源、派生关系、事件核验、缺口、限制和建议触发依据。
- **翻面**：正反面同时存在于稳定容器中，形成真正连续的双面 Y 轴空间关系，不能卸载旧面后只让新面单独转入。按钮为主路径，明确横向拖动为增强；360ms 旋转并保持正反面各自纵向滚动位置。横向手势只有在起始方向明显横向时接管。
- **减少动态**：150ms 交叉淡变或立即切换；隐藏面退出可访问树和焦点顺序；切换后焦点进入新面的标题或返回按钮。
- **禁止**：无黄历干支、印签吉凶、导出或分享入口扩项、精确交易指令和预测文案。

### S10 历史与关于

- **375**：使用 `历史记录`、`关于项目`两个 Tab；历史按时间纵向排列，每项显示状态、快照、证据截止和体验标识。
- **768/1280**：最大宽度 768px；列表与长文保持同一阅读区域。
- **历史**：读取工作区真实 append-only 记录，不展示伪造静态历史；旧记录不按最新数据重算。
- **关于**：说明产品定位、非投资建议、30 天工作区、示例/缓存边界和主动删除。
- **空态**：说明尚无复盘，并提供返回主页发起复盘的按钮。

### S11 满懂图鉴

- **页面任务**：浏览个人收藏并进入单卡成长轨迹，不承担行情或分析仪表盘职责。
- **375**：单列卡片墙；卡片保持约 3:4 稳定比例，翻面和查看轨迹按钮至少 44px，文本允许换行且不横向溢出。
- **768/1280**：使用 `repeat(auto-fit, minmax(220px, 1fr))` 的重复项网格，最大四列；详情恢复单一阅读轴，不把轨迹嵌进卡片。
- **程序化卡面**：由种子控制观测窗格的线距、偏移、方位标和边框组合。常规以纸白、墨色和青绿为主；闪彩增加克制的朱红/金色交叉线；典藏使用更完整的窗格边框与徽记。三档均显示文字标签。
- **交互**：按钮是翻面主路径；卡片聚焦后左右方向键可作为增强。新卡揭示可以关闭且不遮挡报告；复遇不显示提示。
- **删除**：使用明确的二次确认对话框，说明只删除图鉴卡和轨迹、不修改历史复盘。确认后焦点返回合理位置。
- **生成标识**：专业名词显示「AI 生成学习卡」，趣味梗显示「AI 生成趣味内容」；使用 12px/18px 次级文字，不降低到不可读对比度。

## 6. 响应式与无障碍验收

- 核心断点为 375、768、1280px；320px 仍不得横向溢出。
- 正文不被 sticky/fixed 操作栏遮挡；横竖屏都保留退出和返回路径。
- 所有交互可用键盘完成；路由切换后焦点进入新屏主标题。
