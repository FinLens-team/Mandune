## 结论

Bocha Web Search 的项目凭据、最小请求、无效鉴权、本地数量上限、硬超时和一手来源读取已得到可复跑证据，可以交给后续 adapter 票据继续做空结果、限流、畸形响应和生产稳定性验收。

PandaAI 使用国家码 `86` 加手机号作为数据服务登录名后认证成功。`panda-data==0.0.12` 的 `get_stock_detail`、`get_market_data` 和 `get_fund_detail` 已分别得到成功、空集或参数失败证据；`get_fund_pro` 与 `get_fund_nav` 不存在于该 SDK 导出或当前公开 API 树，记录为 `not_applicable`，不能用文档旧清单代替运行能力。

本次证实 A 股基本信息与历史行情、ETF 基本信息、场外基金基本信息可读。ETF 通过 `get_market_data(type=stock)` 在当前窗口和此前声称成功的历史窗口均返回空集，不能认定 ETF 行情已覆盖；场外基金代码则被该方法明确拒绝。ADR-0005 的供应商选择仍成立，MD-007 只能接入本表实际验证通过的方法、字段和资产范围。

## Bocha 运行矩阵

| 场景 | 结果 | 证据 |
|---|---|---|
| 正常最小查询 | `available` | HTTP 200 / 业务码 200，`summary=true`、`freshness=noLimit`、`count=3`，约 516 ms 返回 3 条网页候选 |
| 一手来源 | `verified` | 从候选中独立访问 `sse.com.cn` HTTPS 页面，HTTP 200，约 156 ms |
| `count=51` | `rejected_locally` | 网络未发起，错误为 `count must be between 1 and 50` |
| 无效 Bearer | `auth_failed` | HTTP 401 / 业务码 401；响应摘要不保留密钥或供应商消息 |
| 1 毫秒预算 | `timed_out` | TLS 握手被本地硬超时终止 |
| 伪随机无结果查询 | `available` 但不相关 | 仍返回 1 条无关网页，证明“有结果”不等于相关，空结果本次未观察 |

Bocha 正常响应在本次运行中没有可用 `type` 值；已核验结构为业务码、`data.queryContext` 与 `data.webPages.value`。标题、站点、URL 和发布时间只作为候选定位信息，搜索摘要未保存，也未被升级为物质性证据。
