# 满懂 2 至 3 分钟演示脚本

状态：`录制前脚本`。目标时长 `2:35`，允许在 `2:20-2:50` 内剪辑。画面以最终真实产品为主；字幕和局部放大可以辅助理解，但不能用合成界面代替功能。

## 演示目标

评委在一次普通首次使用中看到：

1. 用户如何确认示例组合和四项约束；
2. Agent 如何以可观察阶段处理输入和证据；
3. 东方观象长笺如何先给出可读结论，再翻到理性证据；
4. 证据不足时产品如何缩小结论，而不是伪造正常结果。

不设置评委专用路由。正常态和有限态都必须从普通入口、可见场景选择或真实用户操作到达。

## 录制前条件

- 使用版本化、明确标注的示例数据。任何出现持仓、金额或建议的画面持续显示 `Simulated` 或等价标记。
- 固定熊猫角色“兜兜”在所有主题中保持同一身份，只更换服饰和环境。旁白和动作只让兜兜观察、解释和承认未知，不让它预测吉凶或替用户决定。
- 示例场景由可见种子或场景标识确定性选择，不临场随机生成资产或数值。
- `PandaAI-style` 透明缓存证据显示来源、观察时间、获取时间、证据截止时点和缓存状态。这个名称只描述演示形态，不表示 PandaAI 或 Bocha 集成已经通过运行验收。
- Agent 观测台只显示允许公开的阶段、角色、输入摘要、状态和结构化产物，不展示思维链。
- 脚本中的按钮、状态和字段必须存在于最终分支。没有实现的镜头直接删除。
- 全程隐藏密钥、管理页、终端凭据、真实账户、真实持仓和个人研究记录。

## 旁白约束

- 使用“帮助理解”“方向性建议”“当前证据支持”等可核验措辞。
- 不说“预测准确”“高置信上涨”“避免亏损”“专业投资意见”或“自动调仓”。
- 不把缓存数据称为实时行情，不把供应商风格示例称为供应商集成。
- 不让兜兜预测吉凶、承诺结果、催促交易或替用户作决定。
- 不声称“Qoder 独立完成产品”或“所有代码由 AI 生成”。
- 没有真实研究证据时，不说“用户都需要”“访谈证明”或具体提升百分比。

## 现场降级

现场网络或外部服务失败时，仍从同一个普通入口选择已提交的透明缓存场景。演示者要主动说明缓存的来源、时点和限制，并展示有限态。不能切换到隐藏评委页、开发者开关、录制假响应或伪造当前值。

分析生成目标为 90 秒、180 秒硬截止。脚本可以使用赛前生成且版本一致的透明缓存结果控制时长，但必须显示它对应的快照、证据截止时点和缓存状态，不得冒充现场实时生成。

## 录制验收

- [ ] 总时长不超过 3 分钟，每个关键字段能停留到可读。
- [ ] 首次使用不是跳过式预置结果，逐行确认、四项约束和快照均可见。
- [ ] 主画面来自最终产品，鼠标和触控动作与实际响应一致。
- [ ] `Simulated` 在所有含持仓、金额或建议的示例画面可见。
- [ ] Agent 观测台至少展开一次真实输入摘要或产物状态。
- [ ] 东方观象叙事正面和理性证据背面引用同一分析版本。
- [ ] 兜兜跨主题保持同一身份；变化只限服饰和环境，职责边界在旁白与界面中一致。
- [ ] 三维翻面有可见按钮替代，核心信息不依赖 hover 或动画。
- [ ] 有限态从普通产品路线到达，并说明仍能确认、不能判断和如何恢复。
- [ ] 无凭据、真实个人金融数据、未脱敏用户记录或供应商越界主张。
