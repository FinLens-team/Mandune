# Dagou Tap audio samples

Source: [MarkCup-Official/Dagou-Tap-New](https://github.com/MarkCup-Official/Dagou-Tap-New)

The original author, MarkCup, explicitly welcomed derivative works and
adaptations provided the author is credited ("欢迎二创，改编，标注作者即可").
These WAV samples are used by Mandune's credited About-page easter egg.

Theme mapping:

- `eastern_observation` / 我是龙: `ha.wav`, `ji.wav`, `mi.wav`
- `jixing_doudou` / 吉星高照: `dingdongji_ding.wav`,
  `dingdongji_dong.wav`, `dingdongji_ji.wav`
- `sunge` / 孙哥: `da.wav`, `gou.wav`, `jiao.wav`
