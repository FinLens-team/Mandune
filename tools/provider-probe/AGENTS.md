# Provider Probe Agent Notes

- 本目录是独立诊断工具，不是产品 adapter；不得从产品源码导入，也不得让供应商类型进入领域契约。
- PandaAI 运行固定为 Python 3.12 与 `panda-data==0.0.12`。凭据从进程环境或根目录已忽略的 `.env` 读取，显式环境变量优先；SDK `user.json` 必须隔离到临时目录并在所有退出路径删除。
- PandaAI 数据服务登录名使用国家码 `86` 加手机号，不是裸手机号；不得把可复现的格式错误写成账号无权限。
- 输出只保留公开测试资产、字段名、类型、空值计数、时点范围、状态、退出码和耗时。不要输出原始响应、完整请求、搜索摘要、凭据或私人组合。
- Bocha `count` 必须在网络请求前限制为 `1..50`；搜索结果仅是候选线索，一手来源验证必须使用明确域名和独立 HTTP 读取。
- `available` 只描述单次调用。空结果、未观察到的限流或缺失 SDK 方法不得升级为资产覆盖。
