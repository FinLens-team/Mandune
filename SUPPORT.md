# Support

Mandune is an early-stage open project and does not provide an operational SLA or personalized investment support.

## Where to Ask

- **Reproducible bug:** open a Bug Report with fictional data and environment details.
- **Product proposal:** open a Feature Request and describe the user scenario and safety boundary.
- **Setup question:** start a GitHub Discussion if discussions are enabled; otherwise open a question-labeled issue only after checking the README and `docs/`.
- **Security or private-data issue:** follow [SECURITY.md](SECURITY.md). Never use a public issue.

## Before Posting

Check [README.md](README.md), [docs/configuration.md](docs/configuration.md), [docs/deployment.md](docs/deployment.md), existing issues, and the latest `main` branch.

Remove or replace:

- API keys, Bearer tokens, cookies, and `.env` contents;
- real names, account numbers, holdings, screenshots, and portfolio values;
- private provider responses and server logs;
- public URLs that grant access to a private workspace.

Maintainers may close requests that cannot be reproduced without private financial data, ask for investment decisions, or fall outside the current project scope.
